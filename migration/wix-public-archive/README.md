# Wix public-site archive

The `2026-09-02/` snapshot was captured before the Playmaker Sports domain moved away from Wix.

- `html/` contains the raw public HTML returned for the six public site pages and seven news articles.
- `media/` contains high-resolution WebP copies of every Playmaker-owned Wix media item referenced by those pages.
- `manifest.json` maps each local file to its source URL and records byte sizes and SHA-256 checksums.

This archive is preservation material, not deploy input. The production build only publishes `dist/`.
